# Readme

Dette er et standard-prosjekt i RStudio. Tanken er at du kan putte alle filer i forbindelse med forelesninger og øvinger i denna mappa.

## Bruk

Last ned datafiler fra Canvas og legg dem i `data` mappe under hhv. `oving` eller `forelesning`. 

## Viktig

Ikke slett filer du ikke veit hva er. F.eks. filer som starter på `.`. Du skal kun ha én `*.Rproj` fil i denne mappa. Hvis du vil lage et nytt R prosjekt, legg det i en annen mappe enn denne.
